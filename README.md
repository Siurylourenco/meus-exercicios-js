# 📚 Meus Exercícios de JavaScript

Este repositório contém meus exercícios de **JavaScript** aplicados no **frontend**.  
Cada exercício está organizado em uma pasta separada, contendo um `index.html` e um `script.js`.  

O objetivo é praticar conceitos fundamentais de **Programação Orientada a Objetos** e **funções em JavaScript**, usando exemplos visuais no navegador.

## 📂 Descrição dos Exercícios

### 🔹 Ex 1 - Objeto Literal
- Exemplo de objeto literal com propriedades e métodos.  
- Ao clicar no botão, o estilo é aplicado dinamicamente.  

### 🔹 Ex 2 - Função Construtora
- Criação de objetos com `new`.  
- Dois contadores independentes que incrementam ao clicar.  

### 🔹 Ex 3 - Classe
- Uso de `class`, `constructor` e métodos.  
- Renderização de **cards de usuários** com botão de "fazer aniversário".  

### 🔹 Ex 4 - Factory Function
- Função fábrica que retorna objetos.  
- Lista de produtos exibida dinamicamente na tela.  

### 🔹 Ex 5 - Prototype
- Método adicionado no `prototype` para ser **compartilhado entre instâncias**.  
- Dois temporizadores que contam segundos ao mesmo tempo.  

### 🔹 Ex 6 - Callback
- Demonstração de função callback.  
- Processamento de nome com atraso simulado (`setTimeout`) e resultado exibido depois.
